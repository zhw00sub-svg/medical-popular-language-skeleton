# 医学科普“人话骨架”库

按读者任务选择骨架。花括号内填入已经核验的医学事实；不需要逐项照搬。

## 1. 概念解释：读者先看见什么，再知道它是什么

```text
读者通常会从{常见体验/检查结果}注意到这个问题。
这里说的{术语}，是指{简明定义}。
它之所以会出现/被重视，是因为{已证实的生理或行为关系}。
这意味着{与读者相关的解释}，但不意味着{常见误解或不能推出的结论}。
如果{需要进一步判断的条件}，应由{角色}结合{信息}决定下一步。
```

适合首次出现的疾病、检查名词、手术术语和风险因素。避免以字典式定义结束。

## 2. 风险与关联：把“风险升高”说成读者听得懂的关系

```text
在{人群}中，{暴露/特征}与{结局}更常同时出现，或与{结局风险}升高有关。
研究观察到的是{具体结果、数据、时间尺度和比较对象}。
这提示{可能的临床含义}；它不说明每位有{暴露}的人都会发生{结局}，也不单独证明{暴露}就是唯一原因。
对个体而言，还要结合{其他决定因素}判断实际风险和处理方式。
```

适合队列研究、流行病学数据、危险因素和预测指标。必须区分“相关”“可能参与”“已证实因果”。

## 3. 症状与就医：先帮助识别，再说明分流

```text
{症状}可以由{常见原因范围}引起，因此单凭{症状}不能直接确定诊断。
如果它表现为{常见且相对稳定的模式}，通常需要在{时间/情境}中记录并与医生讨论。
但出现{明确红旗表现}时，问题不应只按{原来的常见解释}处理，应尽快到{适当场所}评估。
```

适合症状文章、门诊宣教和术后随访。红旗必须具体、直接，不用“必要时及时就医”代替。

## 4. 检查与化验：解释它测到了什么，以及它没替代什么

```text
{检查}主要观察/测量{对象}，因此它能帮助回答{临床问题}。
{结果}说明{在本检查语境下可支持的含义}。
不过，这项检查不能单独回答{它无法回答的问题}；医生还会结合{症状、病史、体征、其他检查}判断。
对读者而言，结果更适合被理解为{下一步决策信息}，而不是给自己贴上的固定标签。
```

适合筛查、影像、内镜、病理和化验说明。避免把“异常”直接翻译为“严重”。

## 5. 治疗与药物：说明目标、受益、代价和决策权

```text
{治疗}的主要目标是{目标}，它通过{已知机制/治疗作用}帮助{适用人群}改善{结局}。
在{证据条件}下，研究显示{可准确表述的获益}。
同时，{不良反应/限制/不适用情形}需要被纳入决定。
是否选择、调整或停止{治疗}，应由{患者与相应专业人员}根据{关键信息}共同决定；不要仅凭{单一体验/他人经验}自行改变方案。
```

适合药物、生活方式治疗、内镜治疗和长期随访。不要把“有效”写成“适合所有人”。

## 6. 手术与操作：把“做了什么”连接到“为什么这样做”

```text
{手术/操作}在{目标解剖或功能}上进行{关键动作}，目的是{直接目标}。
术后{短期变化}与{长期变化}分别可能带来{获益或适应过程}。
它并不是只完成一次操作就结束：{复查、饮食、用药、康复或并发症观察}共同决定安全性和长期效果。
{适应证/禁忌证/替代方案}需要在术前由{团队}结合{信息}评估。
```

适合手术、介入、内镜操作和围术期教育。用正确解剖名词，不把操作写成“修好了就一劳永逸”。

## 7. 日常行为与长期管理：从“具体场景”落到“可执行行为”

```text
在{具体生活场景}中，读者常会遇到{困扰}。
这通常与{可解释的身体/行为关系}有关，而不必立刻把它理解为{自责性或灾难性结论}。
可以先从{明确、低风险的行为}开始，并在{观察期限/随访节点}留意{可观察指标}。
如果{需要专业评估的条件}，下一步应联系{角色}，而不是继续自行加码。
```

适合体重管理、术后进食、慢病自我管理与康复。行动建议必须在已有证据和安全范围内。

## 8. 纠正误解：先承认问题，再重建更准确的理解

```text
把{现象}简单理解为“{常见说法}”很容易，因为{它为何看起来合理}。
但现有证据更支持这样的解释：{完整关系}。
因此，{正确的临床/生活含义}；同时不能据此推到{越界结论}。
真正需要关注的是{观察点或决策点}。
```

只纠正会改变理解或行为的误解。避免反复使用“不是……而是……”作为固定句式。

## 9. 数据与研究结果：让数字服务于理解，而不是成为装饰

```text
这项{研究类型}纳入了{人群}，在{时间}内比较/观察{对象}。
研究发现{数字、结局、比较对象}。
这个结果说明{最稳妥的临床含义}。
由于{研究限制或适用范围}，它不能直接回答{不能回答的问题}；读者仍应把它放回{自身情境}理解。
```

列出相对风险、绝对风险、发生率或比例时，尽量同时写清分母、比较对象和时间尺度。

## 10. 章节结尾：收束理解，而不写成口号

```text
理解{主题}，关键不在于记住一个结论，而在于看清{核心关系}。
对读者而言，眼下最重要的是{可执行且安全的下一步}。
当{边界条件}出现时，再由{角色}帮助把一般规律转化为个体决定。
```

不用“记住三点”“不是你的错”“带走一句话”收尾，除非该书的既定体例确实需要。

## 高频修复清单

将下列空泛表达改成能落地的完整句：

| 空泛表达 | 必须补出的信息 |
| --- | --- |
| “存在风险” | 哪种风险、对谁、在什么条件/时间下、如何处理？ |
| “需要重视” | 谁需要观察什么，为什么，何时找谁？ |
| “综合评估” | 由谁评估哪些信息，评估结果决定什么？ |
| “与之相关” | 关联的是哪两个变量，研究看到什么，不能推出什么？ |
| “个体化处理” | 个体差异主要来自哪些决定因素，谁做决定？ |
| “术后要管理” | 管理哪一项、用什么方式、在何时、警惕什么？ |
